# Welcome to My Blog

This is my first blog post built with Waku! You can write your content here using Markdown.

## Features

- **Markdown Support**: Write your posts in Markdown or MDX
- **Frontmatter**: Add metadata like title, description, author, and date
- **Static Generation**: Posts are statically generated for fast performance

## Code Example

Here's how you can include code snippets:

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet("Waku"));
```

## What's Next?

Start creating more blog posts by adding `.md` or `.mdx` files to the `private/contents` directory!
